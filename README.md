# NewCo Property Portfolio — Investor Document Room

A static, no-login document room for prospective equity partners, hosted on GitHub Pages.

## Files
- `index.html` — the document room (access-code gated list of documents)
- `presentation.html` — the full investor presentation

## Deploy (GitHub Pages)
1. Create a **public** repo named `newco-investor-room`.
2. Upload `index.html` and `presentation.html` (Add file -> Upload files).
3. Settings -> Pages -> Source: **Deploy from a branch**, branch **main / (root)** -> Save.
4. Your room is live at **https://dreyer10-crypto.github.io/newco-investor-room/**

## Access code
Set in each file's script — default `ASV-2026`. Change it before sharing.

Confidential. Sensitive documents (title deeds, full model) are shared privately with verified parties, not published here.
